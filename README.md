# 東京合戦 (Tokyo Conquest) - 東京都全53市区町村 開拓×レトロFF風コマンド合戦

東京都全53市区町村（都心23特別区・北多摩・南多摩・西多摩町村）のどこからでも旗揚げが可能な、ブラウザ完結型の本格地域経営＆レトロRPGコマンドバトル・シミュレーションWebアプリケーションです。

🌐 **本番公開URL**: [https://tokyo-gassen-app.web.app](https://tokyo-gassen-app.web.app)

---

## 🌟 ゲームの主要特徴

1. **東京都全53自治体 自由旗揚げシステム**
   - 23区だけでなく、武蔵野・立川・八王子・町田・青梅・奥多摩・檜原村など、**全53市区町村のどこからでもゲームを開始可能**。
   - 各自治体ごとに固有の名将3名（計159名以上）が最初から配下として従軍。
   - 支配した地域の名将を登用し、自軍の合戦スタメン（3名）へ自由に編成可能。

2. **クラシックRPG（初期ファイナルファンタジー風）3v3コマンド合戦**
   - 昔懐かしいレトロドット絵と臨場感あふれる地域別バトル背景（ネオン街、大河原、武蔵野緑地、山岳渓谷など）。
   - 前列（近接・タンク）と後列（遠隔スナイパー・術士・ヒーラー）の陣形システム。
   - 個別行動ゲージ（ATB / リキャスト風ターン制御）と地域固有のド派手な必殺技演出。

3. **内政・特産品交易・不戦防衛同盟**
   - 毎月の内政行動は所持軍資金の30%までという規律（浪費防止とリアルな時間経過）。
   - 各自治体の【特産品】を調達し、隣接地域へ贈呈することで「不戦・相互防衛協定」を締結可能。
   - 強者が弱者を一方的に攻撃すると「民意」が低下し、民が近隣自治体へ流出するパワーバランサー。

4. **不屈の敗戦再起（即ゲームオーバー防止）システム**
   - 合戦に敗れても即終了せず、資金・兵力の10%割譲と武将1名の軍役貸出で領地を死守。
   - 留守中は能力80%の「代理副官」が奮闘し、地道に国力を再建して下克上を狙えます。

5. **スマートフォン・PC両対応 ＆ だらだらプレイ用ローカルセーブ**
   - マップドラッグ・ズーム、900px以下のモバイルフレンドリーUI。
   - ターン終了ごとの自動保存＋手動保存対応（LocalStorage）。

6. **Feedback Hub ＆ 収益化・相互送客インフラ**
   - `yukiyanart-promo.js`（Feedback Hub 連動 ＆ 自社アプリ相互送客カルーセルバー）。
   - Google AdSense（パブリッシャーID: `ca-pub-5012440476019514`）レスポンシブ広告枠設置。
   - SEO・品質基準を満たす高品質ナレッジアコーディオン（風土記・合戦極意書）。

## 🚀 起動・プレイ方法（ローカル環境）

### 方法A: Windows簡易ランチャー（推奨）
プロジェクトフォルダ内の `start.bat` をダブルクリックするだけで、ポート3000でWebサーバーが起動し、ブラウザが自動的に開きます。

### 方法B: Node.js / npx
```bash
npx serve -l 3000 .
```
ブラウザで `http://localhost:3000` にアクセスしてください。

## 🌐 Web公開・デプロイ手順

### 1. Firebase Hosting による公開
すでに `firebase.json` が同梱されています。
```bash
# Firebase CLIのログイン（初回のみ）
npm install -g firebase-tools
firebase login

# プロジェクトの初期設定（Hostingを選択、public directoryは \".\"、SPA rewriteは \"Yes\"）
firebase init hosting

# デプロイ実行
firebase deploy --only hosting
```

### 2. GitHub Pages による公開
リポジトリの「Settings」→「Pages」にて、`Branch: main / (root)` を選択して「Save」するだけで即時公開できます。

## 📁 主要ファイル構成

- `index.html` - メインゲーム画面、AdSense広告ユニット、プロモバー、攻略ナレッジ
- `style.css` - レトロサイバー戦国テーマCSS（スマホ対応・レスポンシブ）
- `app.js` - UI描画、53自治体旗揚げモーダル、イベントハンドリング
- `game.js` - 地域経営ロジック、同盟・民意・内政行動上限・敗戦再起処理
- `characters.js` - 東京都全53自治体・159名以上の英雄データベース＆スキル定義
- `pixel-sprites.js` - レトロRPG風ドット絵スプライト生成エンジン
- `battle-engine.js` - 3v3コマンドバトル制御、前衛/後衛判定、ダメージ計算
- `battle-backgrounds.js` - 地域別の合戦フィールド背景描画
- `regions-data.js` - 東京都全53市区町村の精密SVGパス・隣接関係データ
- `audio.js` - Web Audio APIによるレトロSE・BGM生成
- `yukiyanart-promo.js` - Feedback Hub連携・自社アプリ相互送客バー
- `firebase.json` - Firebase Hosting用設定
- `start.bat` - Windows用ローカルWebサーバー起動スクリプト
